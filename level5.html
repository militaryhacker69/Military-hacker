🐍 LEVEL 5: PROGRAMMING ACADEMY

Programming ialah cara manusia memberi arahan kepada komputer menggunakan bahasa kod.

📘 Lesson 5.1: Apa itu Programming?

Programming ialah proses menulis arahan supaya komputer melakukan sesuatu tugas.

  • Idea
  • Logik
  • Kod
  • Output

🧠 Lesson 5.2: Programming Logic

Sebelum menulis kod, seorang programmer perlu berfikir secara teratur.

  • Masalah
  • Analisis
  • Penyelesaian
  • Ujian

📦 Lesson 5.3: Variable

Variable digunakan untuk menyimpan nilai atau maklumat.

Contoh konsep:


nama = "Ali"
umur = 20

🔁 Lesson 5.4: Condition & Loop

Komputer boleh membuat keputusan dan mengulang tugas.

  • IF / ELSE
  • FOR LOOP
  • WHILE LOOP

🐍 Lesson 5.5: Python Asas
