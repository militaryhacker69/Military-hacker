🖥️ LEVEL 4: WEB TECHNOLOGY

Belajar bagaimana website dibina dan bagaimana teknologi web berfungsi.

📘 Lesson 4.1: Apa itu Website?

Website ialah koleksi halaman digital yang boleh diakses melalui internet.

  • Browser
  • Server
  • Database
  • Code

🧱 Lesson 4.2: HTML

HTML ialah struktur asas sesuatu halaman web.

Contoh elemen:

  • Heading
  • Paragraph
  • Button
  • Image

🎨 Lesson 4.3: CSS

CSS digunakan untuk mengubah rupa dan gaya website.

  • Warna
  • Susunan
  • Animasi
  • Design

⚙️ Lesson 4.4: JavaScript

JavaScript membuat website menjadi interaktif.

  • Button function
  • Animation
  • Data processing
  • Dynamic content

🌐 Lesson 4.5: Web Communication

Browser berkomunikasi dengan server untuk mendapatkan data.

  • Request
  • Response
  • Server
  • Client
