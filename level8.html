🏢 LEVEL 8: SOC ANALYST ACADEMY

SOC (Security Operations Center) ialah pusat pemantauan keselamatan siber.

📘 Lesson 8.1: Apa itu SOC?

SOC bertugas memantau sistem, mengesan isu keselamatan dan membantu organisasi bertindak balas.

  • Monitoring
  • Analysis
  • Reporting
  • Response

🖥️ Lesson 8.2: Security Monitoring

SOC menggunakan pelbagai sumber maklumat untuk memahami keadaan sistem.

  • System logs
  • Network activity
  • Security alerts
  • Reports

🚨 Lesson 8.3: Alert Analysis

Tidak semua amaran bermaksud ancaman. Analyst perlu memahami konteks sebelum membuat keputusan.

  • Semak maklumat
  • Kenal pasti risiko
  • Dokumentasikan hasil

📋 Lesson 8.4: Incident Response

Proses umum apabila berlaku insiden:

  • Preparation
  • Detection
  • Analysis
  • Recovery
  • Review

👥 Lesson 8.5: Kerja Berpasukan

SOC memerlukan komunikasi yang baik antara pasukan teknologi dan keselamatan.

  • Laporan jelas
  • Kerjasama
  • Mengikut prosedur
