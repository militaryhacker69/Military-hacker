🌐 LEVEL 3: NETWORKING ACADEMY

Networking ialah asas bagaimana komputer, telefon dan server berkomunikasi.

📘 Lesson 3.1: Apa itu Network?

Network ialah sambungan antara dua atau lebih peranti untuk berkongsi data.

  • Computer
  • Phone
  • Server
  • Router

🌍 Lesson 3.2: IP Address

IP Address ialah alamat yang digunakan untuk mengenal pasti peranti dalam rangkaian.

Contoh jenis:

  • IPv4
  • IPv6

📡 Lesson 3.3: Router & Internet

Router menghubungkan rangkaian tempatan dengan rangkaian lain.

  • Mengurus sambungan
  • Menghantar data
  • Menghubungkan peranti

🔎 Lesson 3.4: DNS

DNS menukar nama website kepada alamat IP supaya komputer boleh mencari server.

Contoh: Website name → IP Address

🌐 Lesson 3.5: HTTP & HTTPS

HTTP digunakan untuk komunikasi web. HTTPS menambah lapisan keselamatan menggunakan encryption.
