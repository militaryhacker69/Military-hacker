💻 Level 1: Computer Fundamentals

Tahap pertama sebelum belajar cybersecurity. Faham bagaimana komputer berfungsi.

Lesson 1.1: Apa itu komputer?

Komputer ialah mesin elektronik yang menerima data, memproses maklumat dan menghasilkan output.

Contoh komponen:

  • CPU - otak komputer
  • RAM - memori sementara
  • Storage - tempat simpan data
  • Motherboard - penghubung komponen

Lesson 1.2: Hardware & Software

Hardware ialah bahagian fizikal komputer. Contoh: keyboard, monitor, processor.

Software ialah program yang berjalan dalam komputer. Contoh: Windows, Linux, aplikasi.

Lesson 1.3: Operating System

Operating System (OS) menguruskan hardware dan membolehkan pengguna menggunakan komputer.

  • Windows
  • Linux
  • macOS
  • Android
