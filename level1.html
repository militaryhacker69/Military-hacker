💻 LEVEL 1: COMPUTER FUNDAMENTALS

Selamat datang trainee. Ini adalah asas sebelum masuk dunia cybersecurity.

📘 Lesson 1: Apa itu komputer?

Komputer ialah mesin elektronik yang menerima data, memproses maklumat dan menghasilkan output.

Contoh:

  • Keyboard = Input
  • CPU = Pemproses
  • Monitor = Output

🧩 Lesson 2: Hardware

Hardware ialah komponen fizikal komputer.

  • CPU - otak komputer
  • RAM - memori sementara
  • Storage - tempat simpan data
  • Motherboard - papan utama

⚙️ Lesson 3: Software

Software ialah program yang mengarahkan komputer melakukan tugas.

  • Operating System
  • Aplikasi
  • Driver

🖥️ Lesson 4: Operating System

OS menguruskan hardware dan software.

  • Windows
  • Linux
  • macOS
  • Android

🛡️ Lesson 5: Asas Keselamatan Komputer

  • Gunakan password kuat
  • Kemas kini sistem
  • Backup data penting
  • Jangan pasang aplikasi tidak dipercayai
