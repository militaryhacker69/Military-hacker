🐧 LEVEL 2: LINUX ACADEMY

Linux ialah sistem operasi yang banyak digunakan dalam server, cloud dan bidang keselamatan siber.

📘 Lesson 2.1: Apa itu Linux?

Linux ialah sistem operasi sumber terbuka (open source). Ia digunakan oleh ramai pentadbir sistem dan profesional teknologi.

  • Ubuntu
  • Kali Linux
  • Fedora
  • Debian

⌨️ Lesson 2.2: Terminal Linux

Terminal membolehkan pengguna memberi arahan kepada sistem.

Contoh arahan asas:

  • ls - lihat fail
  • cd - tukar folder
  • pwd - lihat lokasi semasa
  • mkdir - buat folder

📂 Lesson 2.3: File System

Linux menyusun fail dalam bentuk folder dan direktori.

  • /home
  • /etc
  • /var
  • /tmp

🔐 Lesson 2.4: Permission

Linux mempunyai sistem kebenaran untuk mengawal akses fail.

  • User
  • Group
  • Permission
